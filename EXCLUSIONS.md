# Packaging and exclusions

This is a source/assets handoff, not an account export or a verbatim transcript.

Included: current working game files (including uncommitted additions), runtime models/textures/music/voice, editable `.blend`/atlas/concept sources, static review, primary approved reference, rejected-study record, current status/requirements and selected test/pipeline evidence. Main app `build/` generated duplicates are omitted; `index.html` and ready-to-serve review are included. Earlier Fable review excerpts remain labeled historical.

Excluded: `.git` object stores/config/credentials, node_modules, Python/Blender caches, virtual environments, browser downloads, `.env*`, `.openai` hosting control files, redundant archives, `.blend1/.blend2` backups, private DB exports and original personal seed. The fictional demo seed replaces it in `game/` and the existing isolated preview; only `game/storage.js` is adjusted to a handoff-specific storage key. Originals in the working workspace are untouched. No literal adult-gate password is added to handoff prose; the current client-side digest stays in source.

The complete historical chat and every scratch render/environment download are not bundled. Original uploaded text documents were recovered from local attachments and included as historical context. This synthesis distinguishes the latest direct request from old attached-document instructions. Access to ChatGPT tools, Hugging Face, GitHub or Sites does not transfer in a ZIP. Gemini can request assistance in the existing tab as described in `docs/CROSS-ASSISTANT-COLLABORATION.md`.

Inspect `MANIFEST.json` for exact included paths, sizes and SHA-256 hashes; it excludes itself. `provenance/git-status.txt` preserves the original source working-state listing, not a patch that can reconstruct omitted private data. Build/ZIP verification findings are in `provenance/verification.json`.
