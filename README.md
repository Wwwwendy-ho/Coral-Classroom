# Coral Classroom — Gemini handoff

Read [START-HERE.md](START-HERE.md), then [GEMINI-HANDOFF.md](GEMINI-HANDOFF.md).

This is a complete working snapshot for Antigravity / Gemini, separate from the live game. Use GitHub’s **Code → Download ZIP** on this branch to download all source, assets, references and handoff documents together. The branch includes current work not yet in the original game branch. It does not deploy the game.

All ten baby Shelly studies were rejected. The approved organic turtle / stone-and-satin-glass artwork is the target. See `references/APPROVED-organic-shelly-and-stone-glass-world.png` and the current art-direction notes.

Gemini may request help from the existing Coral Classroom ChatGPT/Codex tab, including image generation. See [collaboration instructions](docs/CROSS-ASSISTANT-COLLABORATION.md).

Original personal learner data has been replaced with fictional demo data. Credentials and dependency caches are excluded. Run `python3 tools/serve_handoff.py` after extraction, and open `http://localhost:8820/`.
